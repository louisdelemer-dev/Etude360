# Étude 360 V0.7 — Organisation d’une étude

Site statique pour GitHub et Netlify : importer `index.html` à la racine, répertoire de publication `.` sans commande de build.

Nouveautés : répartition des dossiers aux clercs, préparation progressive chaque journée, notes de synthèse, file des arbitrages, points de contrôle comptables et affectation manuelle. L’arbitrage et les saisies restent sous contrôle du joueur. Les données sont fictives, sauvegardées localement.

Le jeu ne constitue pas un outil juridique ou comptable conforme pour une étude réelle.
