# Étude 360 — V0.8

Simulation fictive de gestion d’une étude de commissaire de justice.

## Nouveautés
- Une seule mise en demeure initiale par dossier ; les relances restent disponibles.
- Date d'envoi affichée dans la situation procédurale.
- La demande de titre exécutoire exige, **dans le jeu**, une mise en demeure et l'expiration de quatre journées simulées.
- Migration tentant de retrouver les mises en demeure antérieures dans l'historique et les actions en cours.
- Sauvegarde locale existante conservée.

**Attention :** une mise en demeure préalable n’est pas une condition légale générale de la procédure d’injonction de payer. Le verrou est une règle volontaire de gestion du jeu et non un conseil de procédure.

Déployer `index.html` à la racine du dépôt GitHub relié à Netlify.
